# Claude Design Handoff — Album

Dieses Paket ist für die eigenständige Weiterarbeit mit Claude am Album-Projekt vorbereitet.

## Dateien

- `CLAUDE-PROMPT.md` — offener Hauptauftrag zum direkten Einfügen in Claude Code.
- `MOTION-PROMPTS.md` — einzelne, aus den sechs Screenrecordings abgeleitete Motion-Aufträge.
- `X-BOOKMARK-INSPIRATION.md` — gefilterte Design-/Motion-Muster aus den 20 neuesten X-Bookmarks und ihre Übertragung auf Album.
- `INSPIRATION-PLACEMENT-PLAN.md` — konkrete Zuordnung dieser Muster zu Reise-, Ideen-, Karten- und Sammlungs-Screens der Expo-App; Planung ohne Codeänderungen.
- `previous-design-review.md` — vorhandene Bestandsaufnahme als optionale Zusatzquelle, nicht als verbindliche Gestaltungsvorgabe.
- `references/` — die zwei vom Nutzer ausgewählten visuellen Referenzen.
- `current-app/` — ausgewählte Screenshots des derzeitigen App-Stands, einschließlich Kartenansicht im Hoch- und Querformat.
- `motion/` — Kontaktbögen aus den sechs Screenrecordings.

Öffne in Claude Code den Album-Projektordner und füge anschließend `CLAUDE-PROMPT.md` ein. Claude kann die Bilder und Quelltexte über die relativen Pfade aus diesem Projekt lesen. Die Dateien dienen als Inspiration und Orientierung: Claude soll daraus selbst eine kohärente Gestaltung entwickeln.
