# Fotos

Echte Prag-Fotos aus `Album/Assets.xcassets`, für die Vorschauen auf höchstens 1200 px verkleinert (JPEG). In der App gelten die Originale.

| letna.jpg | `imgPhotoLetna` | Letná Park (Beispielort) | im Repo nicht dokumentiert |
| cafe.jpg | `imgThumbCafe` | Café-Platzhalter (Essen & Trinken) | im Repo nicht dokumentiert |

Fotos immer mit `object-fit: cover` bzw. `scaledToFill`, ohne Filter oder Tönung. `imgSculpture` (3D-Rendering) und `imgTravelers` werden bewusst nicht verwendet: keine Personen- oder Profilbilder.
